QR code sharing lets anyone view your tournament timer in real time by scanning a code — no account required on the viewing device.

:::tip
If you want someone to **edit** the tournament rather than just watch it, see [Sharing with co-editors](/info/permissions/). The same QR code link is also how co-editors connect to a tournament after their email has been added to the Permissions list.
:::

## Coming from the old Poker Timer app?

The old app's **Remote Control** feature — where both devices typed the same Share ID and Password — has been replaced by two features that cover its uses better:

| What you used Remote Control for | What to use now |
| --- | --- |
| Displaying the tournament on another device — an iPad, laptop, or TV | **QR code sharing** (this page) — viewers just scan a code; no account or password needed on the viewing device |
| Letting other people make changes, like entering knockouts or buy-ins | **[Sharing with co-editors](/info/permissions/)** — grant edit access to specific people by email address |

A few things to know when switching over:

- **Old shares can't be resumed.** Tournaments from the old app are imported automatically, but any share that was running is gone — set up sharing again using the steps below.
- **No more Share IDs or Passwords.** Viewers scan the QR code, or type its short code into a browser — the code `ABC-XYZ` becomes `pokerclubhq.com/j/ABCXYZ`.
- **Sign in first.** Sharing now syncs through the cloud, so you need to be signed into an account on the device running the tournament. Viewing devices don't need an account.

## How it works

When QR code sharing is enabled, a QR code appears on your timer screen. Anyone who scans it (or opens the link) gets a live, read-only view of your tournament that updates in real time as blinds change, players are seated, and the timer counts down.

The QR code links to your tournament through the cloud, so the viewing device receives updates automatically as you run the tournament.

## Enabling the QR code

1. Make sure you're signed into an account (QR sharing requires cloud sync)
2. Open your tournament's timer screen
3. Tap the display settings icon to open the "Show..." menu
4. Tap "Show QR Code" to enable it

The QR code appears in the corner of the timer screen. Tap the QR code to copy the sharing link to your clipboard.

:::note
QR code sharing is only available for tournaments that are linked to your cloud account. If you don't see the QR code option in the "Show..." menu, sign into your account first.
:::

## The read-only viewer experience

When someone scans the QR code or opens the link:

- The app opens (or the web version loads) and connects to your tournament
- They see a live copy of the timer screen that updates automatically
- They can view the timer, table layouts, player information, stats, and log
- They cannot make any changes — it's strictly read-only

This is perfect for:

- **Projecting the timer** on a TV or monitor by opening the link on a connected device
- **Players checking blinds** from their phones without having to look at the main screen
- **Spectators following along** remotely

## Multi-screen setup

A common setup is to run the tournament from your phone while displaying the timer on a larger screen:

1. Sign in on your phone and create/run the tournament
2. Open the QR code link on a tablet, laptop, or smart TV
3. The large screen shows the timer in real time while you manage everything from your phone

Both screens stay synchronized through cloud sync, so the display is always current.

## Disabling the QR code

To hide the QR code from the timer screen, open the "Show..." menu and tap "Hide QR Code." The sharing link remains valid — anyone who previously scanned the code can still view the tournament until you stop the tournament or remove cloud sync.
