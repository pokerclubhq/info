Your feedback directly shapes Poker Club HQ. Whether you've found a bug, have a feature idea, or want to influence what gets built next, there are a few easy ways to get involved.

## Reporting bugs & requesting features

The best way to report a bug or request a feature is to open an issue on GitHub:

**[github.com/pokerclubhq/info/issues](https://github.com/pokerclubhq/info/issues)**

You'll need a GitHub account to create an issue. Signing up is free and only takes a minute. Once you've filed an issue, GitHub will notify you whenever there's an update — so you can follow its progress from start to finish.

When reporting a bug, include as much detail as you can: what you were doing, what you expected to happen, and what happened instead. Screenshots are always helpful.

If you'd prefer not to use GitHub, you can also reach us by email at `support@pokerclubhq.com`.

## Upvoting issues

See an issue that's important to you? You can upvote it by adding a 👍 (thumbs up) reaction. Open the issue and click the smiley face icon at the bottom of the issue description to add your reaction.

Issues with more upvotes are more likely to be prioritized, so this is a great way to have a say in what gets worked on next — even if someone else already reported it.

## Viewing the roadmap

Want to see what's planned, what's in progress, and what's been completed? Check out the project board:

**[Poker Club HQ Project Board](https://github.com/users/pokerclubhq/projects/1)**

The board gives you a high-level view of where the app is headed. You don't need a GitHub account to view it.
