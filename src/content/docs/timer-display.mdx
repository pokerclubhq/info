The timer screen is yours to shape. You can change what it shows, set custom fonts and colors, put a background image behind it — per level or across the whole tournament — and rearrange the content itself.

This page covers the **Show…** menu, which handles what's displayed and how it looks. Three companion pages cover the layout:

- **[Layout & content](/info/screen-contents/)** — rearranging the cells the timer is built from
- **[Widgets](/info/widgets/)** — the ready-made blocks you can drop in
- **[Content](/info/content/)** — the named text items behind every cell

:::note
Customizing the display is a **Director** privilege. Table Captains and players see the timer read-only, with only the QR code toggle available. See [Roles & shared control](/info/roles/).
:::

## The display settings menu

Tap the display settings icon (**Show…**) in the top app bar. The sheet is split into two sections — **Show**, for what the timer displays, and **Customize**, for how it looks — with **Go to level** above both, for jumping the tournament to another level.

### Show

Pick one of these; it decides what the timer screen is showing right now.

- **Current level** — the countdown, blinds, and level information
- **Seating** — the open tables with player positions, arranged to fill the screen. It's blank when no tables are open, and once the tournament is over
- **Payouts** — the prize distribution, joined by the final standings once the tournament is over

Each has its own layout, so the Payouts screen can be arranged completely differently from the countdown.

### Customize

- **Font** — a custom font for the timer text
- **Font color** — a custom text color; clear the selection to return to the default
- **Background color** — a solid background behind the timer; clear the selection to return to the theme default
- **Background image** — an image behind the timer content, drawn edge-to-edge and cropped to fill
- **Layout & content** — turns [edit mode](/info/screen-contents/) on
- **Show/hide chips** — the chip stacks along the edge of the screen, when the tournament has chips still in play. Denominations the blinds have outgrown drop off on their own — see [Chips leave the timer as the blinds pass them](/info/chips/#chips-leave-the-timer-as-the-blinds-pass-them)
- **Show/hide tables** — miniature table diagrams showing seating, when tables exist
- **Show player photos** / **Show player names** — how seated players appear on those diagrams. This one is a single setting for the tournament rather than a per-level choice

**Show/hide chips** and **Show/hide tables** cover the chips and tables the timer places beside your layout. While the layout has a [Chips or Tables widget](/info/widgets/#chips-tables-and-the-qr-code), which puts them in a place of your choosing, the matching switch is left out.

:::note
Light text automatically gets a soft dark shadow, so it stays legible over a busy background image.
:::

### After the tournament ends

Once the last player is knocked out, the chips and the table diagrams drop off the screen on their own. The chips are out of play and the only seat left is the winner's, so the screen gives the space to the results instead — see [When the tournament finishes](/info/widgets/#when-the-tournament-finishes) for what the layout does at the same moment.

This happens in every view, **Seating** included, which is left blank, and the **Show/hide chips** and **Show/hide tables** switches leave the menu, since they'd do nothing. To keep chips or tables on screen after the game, put a [Chips or Tables widget](/info/widgets/#chips-tables-and-the-qr-code) in the layout. A widget stays until its own condition hides it.

## Choosing what a change applies to

Each customization sheet has an **Update:** control that decides how far the change reaches:

- **this level** — only the level you're viewing
- **all blind levels**, **all break levels**, or **all pregame levels** — every level of that type
- **all levels** — every level in the tournament

This lets you set a calm blue background for breaks and an energetic red one for blind levels. The same control appears when you save a [Layout & content](/info/screen-contents/#saving-one-level-or-all-of-them) edit.

:::caution
Choosing **all levels** when individual levels are already customized replaces those customizations. The app warns you first.
:::

## QR code

The QR code that lets other devices watch a live, read-only copy of the timer isn't in this menu. It has its own button in the app bar, next to **Show…**, for creating, showing, hiding, and deleting it. See [QR code sharing](/info/qr-sharing/).

## Reset and import

**Reset to defaults** appears once a tournament has customizations. It opens a list of exactly what you've customized, so you can reset a single thing — the font, say — or choose **All customizations** to start over.

**Import customizations** copies the look of another tournament onto this one, which saves rebuilding a layout you already like. It brings the whole customization set across, including the screen layout and any [content items](/info/content/) it depends on.

## Adaptive layout

The timer arranges its supplementary elements around the main content based on the space available:

- The main content is scaled to fit, so the sizes you set in [Layout & content](/info/screen-contents/#cell-settings) are proportions rather than fixed point sizes — a layout built on a phone still fills a television.
- Rows and columns set to **Auto** turn with the screen, a row on a wide screen and a column on a tall one. The default **Current level** layout does this. See [Rows and columns that follow the screen](/info/screen-contents/#rows-and-columns-that-follow-the-screen).
- **Chips** and **tables** sit below the timer or beside it, whichever way the screen is shaped.
- **Tables** claim more room as more of them are in play — from about a third of the screen at three tables up to about seventy percent at ten.
- The **QR code** panel — the code with its join code printed underneath — drops into whichever corner has room, preferring the bottom right. Only when no corner can fit a scannable code does the layout reserve a strip for it.
- A layout with a **Chips**, **Tables**, or **QR code** [widget](/info/widgets/#chips-tables-and-the-qr-code) shows that one where the widget is, and nothing of it is placed beside the layout.
